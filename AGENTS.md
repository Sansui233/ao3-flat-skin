# AGENTS.md

## Project Purpose

This project develops an AO3 site skin. The style source is organized as SCSS and built from theme files, optional language add-ons, and shared base styles. Development output is used by local preview pages, while release output is written to the `release` directory.

Theme build output uses the `flat-{theme}` naming format. For example, the `bilipink` theme produces `flat-bilipink.css` for the default build and `flat-bilipink-cn.css` when the Chinese language add-on is included.

## Build Commands

Install dependencies:

```bash
pnpm install
```

Run local development:

```bash
pnpm run dev
```

This starts Sass watch mode and the local preview server. The preview server serves HTML pages from `src` and uses `src/skins/base.css` as the development stylesheet.

Compile the current `scss/index.scss` configuration:

```bash
pnpm run scss:build
```

This writes the current entry build to `src/skins/base.css`. To switch the active theme or language add-on for local development, edit the commented `@use` lines in `scss/index.scss`.

Build release files:

```bash
pnpm run build
```

This command runs `scripts/build.mjs`. It automatically enumerates `scss/theme-*.scss` and `scss/lang-*.scss`, creates a default CSS file for each theme, and creates additional theme-language CSS combinations for each language add-on. During the release build, `scss/index.scss` is temporarily rewritten and then restored after compilation.

The release build clears and recreates the `release` directory. Output includes CSS theme files and an `images` directory. The build script copies `src/images` to `release/images`. When `scss/base.scss` contains `/images/imageset.png`, the script looks for `src/images/imageset-{theme}.png`; if that file exists, the CSS URL is replaced with `https://cdn.jsdelivr.net/gh/sansui233/ao3-flat-skin/images/imageset-{theme}.png`. If the themed image file does not exist, the original URL is kept and a warning is printed.

## Main File Structure

`package.json` defines project scripts and dependencies. The main scripts are `dev`, `scss:build`, `scss:watch`, `serve`, and `build`.

`scripts/build.mjs` is the release build script. It enumerates themes and language add-ons, writes release CSS files, rewrites imageset CDN URLs when possible, copies image assets, and restores `scss/index.scss` after the build.

`scripts/dev.mjs` is the local development entry point. It starts Sass watch mode and the local preview server together.

`scripts/live-server.mjs` provides the local preview server. It serves files from `src` and refreshes pages after HTML or CSS changes.

`scss/index.scss` is the Sass build entry. During development, its commented `@use` lines select the active theme and optional language add-on. During release builds, it is temporarily generated by the build script and restored afterward.

`scss/base.scss` contains the shared AO3 skin styles used by every theme build.

`scss/theme-*.scss` files contain theme variables and theme-specific styles. New themes should use the `theme-{name}.scss` naming format so the release build can discover them automatically.

`scss/lang-*.scss` files contain optional language add-on styles. New language add-ons should use the `lang-{code}.scss` naming format so the release build can create matching CSS suffixes automatically.

`src` contains local preview HTML pages, page assets, development CSS output, and image assets.

`src/images` contains image assets. Theme-specific image sets use the `imageset-{theme}.png` naming format. The release build uses this naming rule to decide whether `/images/imageset.png` can be replaced in generated CSS.

`src/skins/base.css` is the development CSS output generated by `pnpm run scss:build` or `pnpm run dev`.

`release` is the generated release output directory created by `pnpm run build`. It should not be maintained as hand-written source.
